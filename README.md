## 🤖 What I'm Building

**PAI** -- Personal AI Infrastructure with 9 agents, 80+ skills, 30K+ indexed documents, and behavioral enforcement hooks that keep the AI from going off the rails

**MCP Servers** -- [Proxmox](https://github.com/rodaddy/ProxmoxMCP-Plus) · [UniFi (125 tools)](https://github.com/rodaddy/unifi-network-mcp) · [HomeKit](https://github.com/rodaddy/HomeMCPBridge) · [Secrets Management](https://github.com/rodaddy/vaultwarden-secrets) · [CLI Bridge](https://github.com/rodaddy/mcp2cli) -- if a service exists, it should have an MCP server

**Production Apps** -- Full-stack platforms for commodity trading research (4-agent LLM architecture, Next.js, PostgreSQL) and debt collection (AI compliance engine, Stripe, Twilio)

**Homelab** -- 4-node Proxmox cluster, 30+ containers, Pi-hole DNS, LiteLLM proxy, n8n workflows, Home Assistant -- all managed with Ansible

**[Audiobook Pipeline](https://github.com/rodaddy/audiobook-pipeline)** -- Audio files → chaptered M4B audiobooks with Audible catalog metadata. Self-hosting is a lifestyle.
